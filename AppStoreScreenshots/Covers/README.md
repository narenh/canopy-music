# Screenshot covers

CanopyMusicCore). Debug builds read them from here in the simulator; they aren't in any app bundle.

[Unsplash License](https://unsplash.com/license) (free for commercial use, no attribution
required), cropped square and resized to 1200 px. Downloaded 25 October 2026. The file name is the
photo's image id.
